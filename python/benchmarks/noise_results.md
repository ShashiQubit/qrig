# Noise with and without qrig

Qiskit 2.5.2, Qiskit Aer 0.17.2, qrig 1.1.0, Python 3.11.14, seed 20260929. Generated by `benchmarks/noise_benchmark.py`; see `NOISE.md` for the method.

*Qiskit*: Qiskit level-3 compilation alone. *qrig*: `QrigControlEquations` first, then the same Qiskit compilation. For each, the transpiler seed (of [0, 1, 2, 3, 4]) with the highest estimated success probability is used. `F` = state fidelity (mean over 3 random product inputs), `P` = Hellinger fidelity of the output distribution for the task input (= probability of the correct answer when it is deterministic), `err↓` = infidelity reduction 1-(1-F_qrig)/(1-F_qiskit), `×` = F_qrig/F_qiskit, ESP = product of (1 - gate error) over all gates, *gate-error events removed* = 1 - λ_qrig/λ_qiskit with λ = -ln ESP (expected number of gate errors per run; does not saturate for deep circuits, but ignores idle decoherence). Rows marked *(scrambled)* have F below 2/2^n for both variants: the output is essentially noise either way, so only the ESP columns are meaningful there.
