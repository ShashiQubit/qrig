# qrig: "One rig to control them all", verified in Lean 4, used from Python

This repository turns the paper *One rig to control them all* into a
Python module, `import qrig`, whose computational core is C code generated by the
Lean 4 compiler from proved-correct Lean code.

**Results:** the consolidated study (130 circuits on all-to-all targets: gate counts,
noise/fidelity, time, T-count, robustness, comparison with TKET and BQSKit) is described
in [`report/qrig_results.md`](report/qrig_results.md). Regenerate it with
`cd python && python3 benchmarks/make_report.py`.

```
report/               consolidated results (Markdown + figures)
Qrig/                 executable core in Lean (no Mathlib); compiled to C
  Core/Circ.lean        controlled-prop syntax (Def. 6) and its semantics A : cP → P₂
  Core/QOmega.lean      exact scalars Q(ω), ω = e^{iπ/4}
  Core/Gate.lean        concrete gate set, exact simulation, unitary, equivalence, dagger
  Core/Classical.lean   Gray codes, multiply controlled NOTs, synthesis β : Perm₂ → cX (Thm 9)
  Core/Simplify.lean    optimiser driven by the control equations
  Core/GateFuse.lean    fusion of one-qubit gates and scalars
  Core/Serialize.lean   text format shared with Python
  Core/Peephole.lean    DAG-level optimiser for lists of multiply controlled gates
                        (control equations (a),(b),(d),(e),(f)); used on Qiskit DAGs
  FFI.lean              the exported C entry point `qrig_call`
QrigProofs/           machine-checked proofs about the core (uses Mathlib)
  Study/                specifications of the study's kernels (incrementer, Hamming
                        weight, membership oracle, QROM, Draper adder) and its metrics
python/               the Python package (see python/README.md)
  qrig/                 Python front end + Qiskit bridge
  qrig/dag.py           Qiskit DAGCircuit pass `QrigControlEquations` (verified core)
  benchmarks/           MQT Bench → DAG → qrig → MQT QCEC pipeline (MQT_PIPELINE.md),
                        noisy simulation with / without qrig (NOISE.md), the
                        all-to-all study (paper_study.py), TKET/BQSKit comparison
                        (compilers_study.py) and the report generator (make_report.py)
  examples/             equation (e) as a DAG node-replacement rule
  csrc/generated/       the C code emitted by Lean (committed)
  csrc/*.c              small C shims (ctypes entry point / pipe server)
  build_native.py       lake build → copy C → cc
  tests/                pytest suite, cross-checked against Qiskit
```

Build and test:

```bash
lake build                                   # core + all proofs
cd python && python3 build_native.py         # regenerate C and native binaries
python3 -m pytest -q tests                   # tests against Qiskit (and MQT, if installed)
pip install .                                # installs `qrig`
pip install qiskit mqt.bench mqt.qcec        # for the benchmark pipeline:
python3 benchmarks/mqt_pipeline.py           # MQT Bench → qrig → QCEC, writes mqt_results.md
pip install qiskit-aer qiskit-ibm-runtime matplotlib   # for the noise benchmark:
python3 benchmarks/noise_benchmark.py        # fidelity under noise with / without qrig
```

See `python/README.md` for the API, the list of proved theorems, and the parts that are
tested but not formally verified.
